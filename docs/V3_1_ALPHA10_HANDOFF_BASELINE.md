# V3.1-alpha10 交接基线 / 复核差异

## 工作流

1. 责任编辑先保存当前期刊。
2. 在“校审轮次 / 交接签收”中确认交接。Studio 使用既有 snapshot 引擎建立 `review-handoff-round-N` 基线。
3. 复核编辑通过“查看版本差异”读取该快照的 `issue.json`，与当前制作稿比较。
4. 差异面板展示元数据、页面、内容块、文章四类变化，可直接定位相关页面。
5. 点击“我已核对当前差异”只记录在交接 sidecar 中的核对时间与当前 issue 指纹。若之后制作稿继续变化，核对自动变为过期。
6. 内部签收要求：本轮 requiredItems 全部显式 `reviewed`，且当前版本差异已核对。

## 边界

- 快照与交接记录均为制作侧数据。
- 不修改 `issue.status`，不自动发布，不写 V3.0 final evidence。
- `final:status` 仍只认正式六项真实证据。
