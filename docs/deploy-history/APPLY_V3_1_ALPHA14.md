# V3.1-alpha14 · 可视化画布 / 批量编排

Alpha14 延续 Alpha11 的沉浸式 Workspace 与 Alpha12/13 的结构化快速导入，把日常排版从“逐块打开参数”升级为“常用编排栏 + 多选批处理 + Reader 画布直编”。

## 核心变化

- Workspace 顶部新增常驻“常用编排栏”：整体版式、段落样式、间距、字号、文字对齐、块宽度、块位置及批量操作均可一层直达。
- 顶层内容块支持 Shift 连选、Ctrl/Cmd 追加选择、全选与清空选择；批量操作仍只写标准块顺序与 `design` 字段。
- Reader 新增受约束的“画布编排”模式：可直接选择块、纵向拖动排序、拖动宽度手柄、吸附到左/中/右位置，并显示辅助参考线。
- 块位置使用可选 `design.alignSelf = left | center | right`；不新增第二套画布数据模型，`issue.json` 继续是唯一事实来源。
- 预览翻页控件改为固定宽度的信息卡和固定尺寸前后按钮，长标题采用省略显示，不再改变导航形态。
- 制作中心整体编辑态字号与表单字号提升，降低长时间校对的阅读负担。
- 媒体工作台原孤立勾选框改成明确的“图片自动优化”开关与说明。
- 语义分页新增续页末尾平衡：避免正文续页只剩一个过短内容块；可合并时回并，否则把前页尾部相关块后移形成完整阅读单元。

## 画布边界

Alpha14 的第一版画布是“受约束的杂志编排画布”，不是任意绝对坐标设计器：

- 拖动主要用于块顺序调整和左/中/右吸附。
- Resize 使用 25 / 33 / 50 / 66 / 80 / 100% 等安全宽度吸附。
- 不把像素坐标、浏览器临时选中状态或控制点写入 `issue.json`。
- 高级精细数值仍保留在“高级设计”中，常用操作优先在 Workspace 第一层完成。

## GitHub 方案复用说明

开发前评估了 Daybrush Moveable / Selecto / Guides 的交互模型。Alpha14 当前 Full Source 为保证 `/new-jc-magazine-admin/` 离线、自包含部署，采用本地受约束画布适配层实现同类交互，不依赖 CDN，也没有把第三方运行时作为 Reader 必需依赖。后续如正式 vendor 上游发行文件，可在不改变 `issue.json` 数据模型的前提下替换交互适配层。

本版未引入 Paged.js；分页修复仍由现有语义分页器的末页平衡逻辑完成。

## 证据边界

Alpha14 不修改 V3.0.0 正式发布门禁逻辑，不改变 `issue.status`，不把画布选择状态写入 sidecar 或正式发布证据。开发 smoke / Chromium / Studio PASS 均不等于 V3.0 正式门禁 READY。
