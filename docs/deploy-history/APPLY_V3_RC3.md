# V3.0-RC3 快速成刊 + 可调工作区

RC3 在 RC2 门禁体系上只增强制作效率与工作区空间利用，不改变线上 `/1/`、`/2/` 稳定目录。

## 主要变化

- 左侧期刊导航可收束到约 72px，并记忆状态。
- 页面结构栏可收束到约 66px，并记忆状态。
- 编辑区与真实 Reader 默认 5:5；支持编辑优先、预览优先、最大预览。
- 桌面端可拖动中间分隔条，编辑区占比限制在 30%～70%，并记忆宽度。
- 真实 Reader 继续支持五档 viewport 和独立全屏预览。
- 内容快速导入新增“一键成刊预览”：生成页面 → 可选自动目录 → 保存/快照 → 日常审计 → 构建 → Reader 同步。
- 一键成刊不会自动把期刊改为 ready，也不会自动部署服务器；正式发布仍须通过既有 release / RC gate。

## 本地运行

```bash
npm run verify:core
npm run studio:v3 -- --port 4183
```

Safari/iPhone 实机验收台：

```bash
npm run rc:safari
```

RC3 默认端口为 4184。
