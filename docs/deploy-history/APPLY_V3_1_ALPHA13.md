# V3.1-alpha13 · 动态板块语义识别

Alpha13 延续 Alpha12 的整期结构快速导入，把固定五类栏目识别升级为动态板块分类。

## 核心变化

- DOCX `Heading1` 可直接作为新板块边界，不要求使用“第N版块”固定命名。
- 同时继续兼容“第一版块 / 第二版块 ……”格式。
- 板块语义由标题、栏目副题、专题标题、文章标题及前几段正文共同判断。
- 当前语义类别：时政新闻、理论学习、安全防范、纪法警示、健康养生、金融知识、人物风采、文化文苑、服务生活、活动纪实、通用栏目。
- 新语义不会扩张 `issue.json` 的页面类型 schema：profile / culture / finance 等仍安全映射到 `article`，已存在的 news/theory/safety/discipline/health 保持原类型。
- 无法可靠判断时回退 `general -> article`，并在导入预览中标记“待确认”。
- 导入预览支持逐板块人工修改分类；修改后对应导入页面类型立即同步。
- 分类同时给出版式建议，但只作为制作建议，不自动改变正式发布状态。

## 证据边界

Alpha13 不修改 V3.0.0 正式发布门禁逻辑，不改变 `issue.status`，不新增 Reader 运行时依赖。开发回归 PASS 不等于 V3.0 正式门禁 READY。
