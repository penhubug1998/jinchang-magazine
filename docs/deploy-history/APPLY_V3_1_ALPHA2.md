# V3.1-alpha2 可视化样式设计器

版本：`3.1.0-alpha.2`

## 覆盖安装

将 overlay 解压到完整 `jinchang-magazine` 项目根目录，再执行：

```bash
npm run verify:core
npm run studio:v3 -- --port 4189
```

## 本版核心

- 全刊 Theme → 页面 → 组件三级样式继承。
- Studio 顶部新增“设计”，内容块/容器子块新增“◈ 设计”。
- Theme：主色、纸张色、正文色、次级色、基础字号、圆角、间距。
- Page：背景、文字、强调色、页内留白、内容宽度。
- Block：字号、字重、颜色、背景、内外边距、圆角、边框、阴影、对齐、宽度。
- 未设置字段自然继承上级；“恢复继承”不会复制上级数值到子级。
- Reader 真实渲染；Studio 实时 Reader 同步。
- 服务端校验参数范围；审计提示过小字号、过窄内容区等可读性风险。

## 兼容性

V3.0.0 稳定发布锁继续绑定 `v3StableVersion=3.0.0`，V3.1 开发不会让 V3.0 正式门禁自动变绿。
