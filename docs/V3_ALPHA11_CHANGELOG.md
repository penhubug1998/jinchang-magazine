# V3.0-alpha11 变更说明

## 目标

Alpha11 将制作中心从“单页可视化编辑器”推进为更安全的专业编辑工作台，重点解决大批量页面编辑、误操作恢复、浏览器刷新丢稿以及已发布历史刊修订状态不清晰的问题。

## 主要变化

### 1. 页面多选与批量处理

页面结构栏新增复选框和批量工具条，支持：

- 选择当前筛选结果；
- 批量上移 / 下移；
- 批量设置栏目归属；
- 批量删除可删除页面；
- 一键清除选择。

结构页边界继续生效：封面和尾页不会被批量删除或移动出合法位置；栏目批量设置会自动跳过封面、目录和尾页。

### 2. 多级撤销 / 重做

顶部新增 `↶ / ↷` 编辑历史控制。页面结构调整、内容块结构调整、批量操作、JSON 修改等都会进入编辑历史。

快捷键：

- 非输入状态下 `Cmd/Ctrl + Z`：撤销；
- 非输入状态下 `Cmd/Ctrl + Shift + Z` 或 `Ctrl + Y`：重做；
- 输入框内仍保留浏览器原生文本撤销，不抢占文字编辑快捷键。

### 3. 自动草稿与刷新恢复

未正式保存的编辑会延迟写入项目根目录的 `.v3-drafts/<issue>.json`。该目录已加入 `.gitignore`。

自动草稿与正式保存使用不同边界：

- 自动草稿允许“编辑到一半”的中间态，例如标题暂时为空；
- 正式保存仍执行完整 V3 服务端校验；
- 浏览器刷新、标签页隐藏或切换期刊前会尽力落盘草稿；
- 再次打开期刊时，若磁盘上存在与正式版本不同的草稿，会显示恢复对话框；
- 可选择“恢复草稿”或“丢弃草稿”。

### 4. 已发布历史刊的未发布修订

对 `published` 的第一期 / 第二期在制作中心正式保存修改后，源稿会写入：

```json
"revision": {
  "pending": true,
  "source": "studio"
}
```

制作中心期刊列表和状态徽标会显示“未发布修订”。审计增加 `UNPUBLISHED_REVISION` 提示，避免把“源稿已改”误认为“线上已更新”。

`publish:v3 -- --issue XXX --mark-published` 在发布包生成成功后可显式清理该 pending 状态。

### 5. 顶部操作收敛

原本不断横向增长的按钮被整理为：

- 内容；
- 资源；
- 检查；
- 预览；
- 撤销 / 重做；
- 保存。

移动端操作菜单使用底部浮层，避免 320px 极窄屏横向溢出。

### 6. “放弃未保存修改”独立化

Alpha10 的单一“恢复保存状态”能力从撤销按钮中拆开：

- `↶ / ↷` 只负责多级编辑历史；
- “内容”菜单中的“放弃未保存修改”恢复最近一次正式保存状态，并同步删除自动草稿。

## 安全原则

- V3 Studio 保存不会直接覆盖旧线上 `/1/`、`/2/`；
- 历史刊修改仍先建立正式保存快照；
- 自动草稿不是正式发布数据；
- 正式发布仍必须通过发布前检查和浏览器回归。
