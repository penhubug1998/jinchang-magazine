# V3.0-alpha3 浏览器回归说明

## 执行

```bash
npm run build:v3
npm run test:browser
```

完整验证：

```bash
npm run verify:v3
```

## 五档视口

| 设备档 | 尺寸 | 核心检查 |
| --- | --- | --- |
| iPhone | 390×844 | 单页、跟手拖拽、工具栏避让 |
| Android | 412×915 | 单页、视频页、正文滚动 |
| iPad | 820×1180 | 双页书本、首跨页语义 |
| Desktop | 1366×768 | 双页占屏、正反向 3D 翻页 |
| Desktop | 1920×1080 | 大屏缩放、字号与书页比例 |

## 自动断言

浏览器回归会检查：

- 页面初始化完成且没有运行时异常；
- 无横向溢出；
- 手机首屏只有封面；
- PC/iPad 首屏为“空白 + 封面”；
- 手机拖拽从第 1 页进入第 2 页；
- PC 下一跨页聚焦第 3 个阅读页，随后可反向回到封面；
- 文章详情弹窗可打开且保留原文链接；
- 目录包含 29 个阅读页；
- 4 档字号状态可更新；
- 视频使用 metadata 预加载并可进入自定义全屏。

## 容器环境说明

当前开发容器中的 Chromium 受组织策略限制，不能通过 `127.0.0.1` 打开本地预览地址。为了仍然执行真实浏览器回归，测试脚本通过 DevTools Protocol 将构建后的 HTML、CSS、JS 与期刊数据直接注入 Chromium 文档，再执行尺寸模拟与交互测试。这只影响自动化测试的装载方式，不改变正式构建产物的运行方式。
