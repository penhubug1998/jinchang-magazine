# 默认整刊模板

新增三套可编辑整刊模板，每套 8 页：封面、目录、五种内页、封底。

| 模板 | 标识 | 适用场景 | 内页 |
|---|---|---|---|
| 丹心红 · 单位综合刊 | unit-red | 单位内刊、工作交流 | 卷首语、要闻、人物专访、活动剪影、生活随笔 |
| 知行蓝 · 学习专题 | study-blue | 专题研读、业务学习 | 导读、研读、观点交流、实践笔记、延伸阅读 |
| 青禾绿 · 活动纪实 | life-green | 活动记录、生活纪念册 | 开篇、活动足迹、相册、人物故事、心声寄语 |

## 使用

制作中心 → 新建一期 → 填写主题 → 选择整刊模板 → 创建。

默认仍选中原有“标准栏目骨架”。选择“复制已有期刊”后，整刊模板选择区会禁用；取消复制后可重新选用。模板加载失败不会阻止标准建刊。创建按钮在请求期间禁用，避免重复提交。

创建后，可编辑文字、替换图片、添加或删除普通页面，沿用原有保存、校审、朗读和发布流程。模板示例文字用【】提示填写；装饰插画为本地 SVG，可通过页面设计替换背景，通过素材工具替换内页图片。发布前填写真实稿件。

CLI 同样支持：

```bash
npm run new:issue -- --template unit-red --subtitle '本期主题'
npm run new:issue -- --template study-blue --subtitle '本期主题'
npm run new:issue -- --template life-green --subtitle '本期主题'
```

## 实现

- `src/studio/issue-templates.js`：模板目录、现有 page/block 数据与本地 SVG 工厂。
- `GET /api/issue-templates`：返回可选模板；受现有后台登录保护。
- `POST /api/issues`：支持 `templateId`；与 `cloneFrom` 互斥，未知模板返回 400。
- `scripts/new-issue-v3.mjs`：支持 `--template`；素材复制到新一期自己的 `assets/image`。
- 不新增内容 schema；每次生成独立数据对象，不引用历史刊物资源。
- 新模板不绑定不存在的音乐和逐页音频；仍支持浏览器朗读，后续可生成自然语音。
- Reader 支持显式封面文字色与内页强调色；未指定这些颜色的旧刊保持原来的默认颜色。自定义页面背景不叠加旧版装饰。
- 已更新制作端与 Reader 构建缓存标识。上线功能需要更新制作端源码并重启现有后台进程；旧刊无需批量重建，新刊沿用正常构建发布。

## 验证

`npm run test:default-templates` 在隔离目录验证 3 套模板的独立副本、目录页码、资源完整性、真实 CLI/构建、API 创建与保存、非法模板和互斥输入、标准建刊与复制旧刊。测试已加入 CI。

本次通过：模板专项测试、数据校验、构建、阅读器冒烟、登录与源稿保护测试。另在真实 Edge 中完成可视化建刊、桌面模板选择与双页检查，以及 390px 视口下模板卡片和三套共 24 页的溢出检查。手机视口模拟不等于 Safari/微信实机验收，替换成长篇稿件后需重新检查版面。

模板中的“待补充”文字会被发布前严格检查识别；所有正文页与封底都需要替换占位文字，才可通过内容检查。
