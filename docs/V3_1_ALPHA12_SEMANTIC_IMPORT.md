# V3.1-alpha12 语义快速导入设计

## 1. 为什么需要语义导入

旧导入流程主要解决“把一篇长文章放进制作中心”，其基本模型是：解析文本 → 计算内容权重 → 按目标字数分页。对于完整一期期刊，这会导致版块边界丢失、栏目归属为空、目录污染、标准新刊骨架被重复保留。

Alpha12 将导入分为两种路径：

- `article-flow`：普通单篇文章，保持兼容。
- `periodical-structure`：完整电子期刊，按编辑语义重建正文。

## 2. 结构判断

DOCX 优先使用 Word 原生大纲：

- Heading1：整刊标题 / 大版块 / 尾刊入口
- Heading2：卷首语 / 栏目内文章
- Heading3：案例、提醒、警示、建议等文章小节

同时使用中文结构表达兜底：`第一版块`、`第二版块`、`卷首语`、`尾刊寄语` 等。

只有结构证据达到完整期刊阈值时，`auto` 才进入 periodical 路径；普通 DOCX / Markdown / TXT 继续使用文章路径，避免误判。

## 3. 页面结构映射

版块名称映射页面类型：

- 时政 → news
- 理论 / 学习 → theory
- 安全 / 反诈 → safety
- 警示 / 纪律 → discipline
- 养生 / 健康 → health

每一个栏目文章至少拥有独立首屏；长文章可以产生续页。续页保留原 section / pageType，但使用较短 continuation title。

## 4. 内容块语义

除了普通 paragraph，还会根据小节和文本形态产生：

- `cardline`
- `casePair`
- `chips`
- `paragraph:subhead`

以便导入后能更接近期刊成品，而不是全部变成普通正文。

## 5. 整期重建

`publication` 写入方式：

1. 保留现有 cover。
2. 保留现有 toc。
3. 删除标准骨架正文 / 旧正文页面。
4. 写入语义分页结果。
5. 如果导入包含 closing，则替换旧 closing。
6. 标准骨架封面仍为占位标题时，使用导入文件总标题。
7. 后续“自动目录”根据 `section` 只生成真实栏目。

该操作必须用户显式确认。

## 6. 分页策略

目标不再是压缩页数，而是“快速得到可精修的电子期刊结构”。

- 尊重文章边界。
- 优先在 Heading3 小节边界拆页。
- 单页最多 10 个内容块。
- 长段落允许句级拆分。
- 尾页过短时允许在安全范围内与上一页合并。

## 7. 第三期回归结果

真实第三期 DOCX：5 个版块 / 23 篇文章 / 39 个语义内容页；标准骨架整期重建后共 41 页，目录 5 项，最大 10 blocks/page。

开发审计：score 88 / warnings 3；三个 warning 全是 draft/BGM/TTS 制作阶段项，没有导入结构类 warning。
