# V3.0-alpha10 Changelog

## 目标

Alpha10 继续收紧制作中心首屏信息层级。页面级基础字段不再长期占据编辑区上方空间，同时补上历史刊修订时最容易误操作的保存确认与未保存撤销能力。

## 页面信息折叠

- `导航标题 / 页面类型 / 栏目归属 / 页内眉题 / 主标题` 收纳进 `PAGE INFO` 折叠卡。
- 默认收起，仅显示当前页标题、导航标题、类型、栏目和眉题摘要。
- 折叠状态写入 `localStorage`。
- 审计定位到页面字段时自动展开并聚焦。
- 320–1920px 边界回归均验证折叠卡不会横向越界。

## 修订安全

- 顶部新增“撤销修改”，仅在存在未保存内容时可用。
- 已发布历史刊被修改时，保存状态显示“已发布稿 · 有未保存修订”。
- 手工保存先打开“保存前差异确认”，按元数据、页面、内容块、文章四类归纳变化。
- 已发布历史刊在保存确认中明确提示：保存 V3 源稿不会直接覆盖线上 `/1/`、`/2/` 稳定目录。
- 保存仍由服务端先创建 `studio-before-save` 快照，再写入 `issue.json`。

## 页面复制

- 普通内容页支持一键复制并插入当前页之后。
- 封面、目录、尾页属于结构边界页，不允许直接复制。
- 页数达到 200 页上限时阻止复制。
- 超长导航标题复制时会为“（副本）”预留字符，不会把后缀截掉。

## 回归

Alpha10 新增 `test:alpha10`，并扩展制作中心真实 Chromium 回归，覆盖：

- 页面信息默认折叠；
- 审计定位自动展开页面信息；
- 页面复制；
- 保存差异弹窗边界；
- 未保存撤销；
- 320×740、390×844、768×1024、1366×768、1920×1080。

### 差异噪声控制

保存差异不会简单按数组下标逐页比较。插入/复制页面后，系统会先按页面签名重新对齐旧页与新页，再报告真正新增、删除和修改的页面，避免“插入 1 页却显示后面几十页全部变化”的假噪声。
