# V3.0-alpha13 变更记录：内容快速导入

Alpha13 将制作中心从“逐页手工录入”推进到“外部内容 → 结构化识别 → 分页建议 → V3 页面”的快速生产流程。

## 主要新增

- Word / Markdown / TXT 导入：支持 `.docx`、`.doc`、`.md/.markdown`、`.txt/.text`。
- 粘贴正文：自动判断 Markdown / 纯文本，也可手工指定格式。
- 内容识别：标题、小标题、正文、引用、有序/无序列表统一转换为 V3 blocks。
- 长文章分页：按内容密度给出 1～N 页建议，长段落先按句子拆分，再进入分页器。
- 批量文章：一次选择最多 30 个支持文件，逐个解析并统一预览后加入期刊。
- 栏目骨架：从其他 V3 期刊复制正文栏目/页面结构，不复制旧正文、媒体绑定和文章绑定。
- 我的模板：当前页面可保存为个人页面模板；媒体路径、articleId、目录跳转会被清空，避免跨期误引用。
- 导入结果统一进入现有撤销/重做、自动草稿、保存差异、未发布修订、TTS 过期检测流程。

## 重要边界

- 单文件最大 12 MB。
- 单份解析文本最大 400,000 字符。
- 单次自动分页最多 80 页。
- 单页最多 80 blocks。
- 期刊总页数仍受 200 页上限保护；超过上限时在修改数据前阻止应用。
- 分页目标密度实际限制在 320～1400，制作中心提供 520 / 760 / 1000 / 1250 四档常用值。
- 我的模板最多 50 个。
- 批量文件导入最多 30 个文件。

## DOC/DOCX 说明

- `.docx`：直接读取 Word XML，不新增 npm 运行依赖。
- `.doc`：macOS 优先使用系统 `textutil`；其他系统如果存在 `antiword` 或 `soffice` 会自动尝试；若均不可用，提示用户另存为 `.docx`。

## 不变的安全原则

- 导入不会直接覆盖线上 `/1/`、`/2/`。
- 栏目骨架只复制结构，不复制历史媒体文件。
- 导入应用后仍然必须经过审计、构建和浏览器回归才能发布。
