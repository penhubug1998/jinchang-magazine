# V3.1 Alpha29：媒体待补清单

## 本阶段目标

让普通用户能快速回答两个问题：哪些页面还缺图片/视频？从哪里可以直接补上？

## 已完成

- 图片/视频空路径，以及“（图片）”“（视频）”“占位”等来源标记，会显示为“待补素材”。
- 素材库增加“待补素材”筛选，列出页码、页面标题、媒体类型、块位置和稳定 ID。
- 清单提供“定位页面”和“选择图片/视频”入口；替换流程会直接进入对应媒体类型，不需要重新寻找页面。
- 已有媒体库的上传、替换、媒体引用关系和只读目录保护保持不变。
- 扫描只读期刊 JSON，不会自动修改文章正文、标题、链接或媒体占位块。

## 验证

运行：

```bash
npm run test:v31-alpha29
```

该冒烟测试覆盖待补识别、已绑定资源排除、清单生成、UI 入口和“不修改内容”约束。
