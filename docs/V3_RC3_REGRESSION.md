# V3.0-RC3 Regression

RC3 重点验证工作区尺寸与快速成刊不会破坏冻结链。

## 专项断言

- 1366×768：期刊栏收束后 <= 80px。
- 1366×768：页面结构栏收束后 <= 75px。
- 5:5：编辑与预览宽度差 < 65px。
- 自定义 38%：预览区宽于编辑区，比例标签正确。
- 最大预览：预览主体宽度 > 800px。
- 390×844：无横向越界，桌面分隔/收束控件隐藏。
- 快速导入：页面新增、保存、审计、构建、live preview 均实际触发。
- 一键成刊后切回真实 Reader，并定位至导入内容页。
