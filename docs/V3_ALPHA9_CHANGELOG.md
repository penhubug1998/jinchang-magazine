# V3.0-alpha9 Changelog

日期：2026-08-22

## 目标

Alpha9 不继续扩张编辑器功能面，优先解决制作中心的信息架构与历史刊编辑缺口：桌面首屏直接进入编辑工作台，同时把第一期旧版 HTML 迁移为 V3 结构化数据。

## 制作中心工作台重构

- 桌面端改为 `100dvh` 固定工作台。
- 左侧期刊栏固定，期刊列表独立滚动。
- 顶部操作重新分为资源、审计、预览/保存三组。
- 期刊元信息默认折叠，只显示一期摘要；展开后编辑期名、本期主题、状态和发布单位。
- 折叠状态记入 localStorage。
- 中间页面结构与右侧页面编辑分别独立滚动。
- 当前页页头在编辑区内吸顶。
- 审计中心桌面端改为右侧覆盖抽屉，不再把主编辑区向下推。
- 快照与任务输出移到当前页编辑器底部的次级区域。
- 900px 以下回退为正常纵向页面，避免窄屏强行三栏。

## 第一期开启 V3 可编辑

`issues/001/issue.json` 已由 legacy 占位升级为真实 V3 数据：

- 18 个阅读页：封面 + 内页 01–17。
- 保留原 5 篇文章弹窗数据。
- 保留 `legacyPath: ../../1/`，旧 `/1/` 不删除、不覆盖。
- 继续复用 `1/assets` 的背景音乐、18 个 TTS 与纪律提醒视频。
- 创建 `issues/001/assets.json` 资源清单。
- 不向历史正文额外新增旧刊不存在的内容块。

第二期状态同步修正为 `published`，制作中心不再出现状态下拉框空白。

## 回归门禁

新增 `test:alpha9`：固定检查第一期页数、标题顺序、文章 ID、资源清单、历史路径以及工作台结构。

新增 `test:browser:001`：第一期也执行 390×844、412×915、820×1180、1366×768、1920×1080 五档真实 Chromium 回归。

制作中心浏览器回归新增桌面硬断言：

- 左侧栏铺满 viewport 且固定。
- 元信息默认折叠。
- document 本身不承担桌面工作台纵向滚动。
- 页面结构与页面编辑均在首屏可见。
- 48 页页面列表独立滚动。
- 页面编辑区独立滚动。
- 审计定位元数据时自动展开元信息并聚焦字段。

## 兼容性

Alpha9 overlay 仍不包含 `/1/`、`/2/` 和大型媒体文件。合入完整仓库后构建器会继续从 `1/assets` / `2/assets` 复制媒体；线上稳定目录不会因 V3 构建自动改写。
