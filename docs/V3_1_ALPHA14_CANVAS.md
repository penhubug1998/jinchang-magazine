# V3.1-alpha14 · 可视化画布与批量编排

## 1. 操作模型

Alpha14 把高频排版动作从高级参数面板前移到 Workspace 常用编排栏。用户先选择一个或多个顶层块，再直接修改段落、间距、字号、对齐、宽度与位置。

多选语义：

- 单击：单选。
- Shift：按当前顶层块顺序连续选择。
- Ctrl / Cmd：追加或取消单个选择。
- “全选本页”：选择当前页全部顶层内容块。
- “清空”：退出批量选择。

## 2. Reader 画布直编

开启“画布编排”后，Reader 当前页的顶层块显示交互轮廓：

- 点击块：同步选中 Studio 对应块。
- 拖动 `⋮⋮`：调整块顺序；接近相邻块时显示参考线。
- 水平拖动超过阈值：吸附为 left / center / right。
- 拖动 `↔`：修改块宽度，并吸附到 25 / 33 / 50 / 66 / 80 / 100%。

画布只编辑顶层块，不穿透修改容器内部子块，避免在第一版中引入不可控的嵌套绝对布局。

## 3. 数据持久化

Canvas UI 状态不持久化。能够写入 `issue.json` 的只有：

- 顶层块数组顺序；
- `block.design.width`；
- `block.design.alignSelf`；
- 快速编排栏写入的既有标准 design 字段。

`alignSelf` 允许：`left | center | right`。未知值会被 Studio server / schema check 拒绝。

## 4. 与第三方画布库的关系

Moveable / Selecto / Guides 用于确认成熟的交互范式，但 Alpha14 交付运行时采用项目内自包含适配层，不从 CDN 拉取脚本。这样线上制作中心在内网或外网受限环境也能工作，并避免把第三方 DOM/Canvas 数据模型引入 Reader。

## 5. 高级设计

常用编排栏不替代高级设计。渐变、阴影、精细 padding/margin、Theme/Page/Block 继承与其他低频参数仍进入“高级设计”，保持主工作区简洁。
