# V3.1-alpha14 Changelog

- Workspace 新增常驻快速编排栏：版式、段落、间距、字号、对齐、宽度、块位置与批量动作。
- 顶层内容块新增多选、Shift 连选、Ctrl/Cmd 追加选择、全选和清空选择。
- 批量支持段落样式、间距、字号、文字对齐、宽度、位置、上移、下移、复制、删除。
- Reader 新增受约束画布直编：选择、拖动排序、宽度调节、左/中/右吸附及参考线。
- Block `design` 增加可选 `alignSelf`，仅允许 left / center / right；Reader 与 Studio 校验同步。
- 固定 Workspace 翻页导航尺寸，长标题不再改变导航条长度。
- 提升制作中心编辑态字体、表单和内容卡可读性。
- 媒体工作台“图片自动优化”开关增加明确文字说明。
- 语义分页新增 continuation tail rebalance，减少“续1只剩一句/一个短块”的突兀分页。
- 保持 Alpha13 动态板块识别、Alpha12 整期重建、Alpha11 Workspace 及更早能力兼容。
