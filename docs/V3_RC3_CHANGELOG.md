# V3.0-RC3 Changelog

## 快速成刊

- 快速导入中心增加“一键成刊预览”。
- 支持在一次流程中生成页面、自动目录、保存并创建快照、日常审计、静态构建和真实 Reader 同步。
- 保留“仅生成页面”路径，便于先人工编辑再保存。
- 快速链不会绕开 ready / release:check / deploy 等正式发布门禁。

## 可调工作区

- 左侧期刊导航可收束/展开。
- 页面结构栏可收束/展开。
- 编辑器与真实 Reader 默认 50:50。
- 提供编辑优先、5:5、预览优先、最大预览四个预设。
- 桌面端支持拖动分隔条，自定义 30%～70% 编辑占比。
- 布局偏好写入 localStorage；移动端自动回退纵向布局。
- Reader 预览窗口增高，并保留全屏预览。
