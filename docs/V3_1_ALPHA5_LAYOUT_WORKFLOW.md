# V3.1-alpha5 整页模板与智能套版

## 1. 三种制作侧资产分工

### 我的模板

保存整页结构、占位正文和页面样式，用于“新建一页/替换一页”。跨期使用时图片、视频、文章绑定会递归清空。

### 我的样式

保存 Theme / Page / Block 的 design 值，用于视觉复用。

### 我的版式

只保存“内容应该放在哪些容器槽位”的 blueprint，不保存具体正文。用于对当前页已有内容重新排版。

三者都位于项目本地，均不是 Reader 运行时依赖。

## 2. 为什么套版先展平内容

旧页面可能已经包含单栏、双栏、三栏或图文 container。直接在 container 外再包 container 会触发 V3.1-alpha1 的“禁止容器嵌套”边界。

Alpha5 因此先把 container 的叶子内容块按阅读顺序取出，再用目标版式重新组成合法 container。这样：

- 不会出现 container 套 container；
- 媒体块本身不被替换；
- 旧 Block design 保留；
- 全局撤销仍能一次回到套版前页面。

## 3. 智能建议不是生成式 AI

建议器使用固定规则和分数：

- 有图片/视频：优先图文并列；
- 卡片/要点较多：优先三栏速览；
- 正文较长或块数较多：优先均衡双栏；
- 内容较少：优先单栏聚焦；
- 多内容块：补充“首屏重点 + 双栏”。

同一页同一内容会得到相同建议。它不会联网、不会改写正文、不会自动落版。

## 4. 版式资产安全边界

版式 blueprint 只允许：

- `slot`
- `container`

`slot` 除 `kind` 外不得带任何字段，因此不可能保存正文。`container` 只允许 V3 已支持的 layout / gap / align / mobile / design / columns。服务端会再次校验，而不是信任前端。
