# RC3 快速成刊与工作区

## 快速成刊预览

导入 Word / Markdown / TXT 或粘贴正文后，可选择：

1. 生成结构化页面；
2. 自动刷新目录；
3. 保存 V3 源稿并建立快照；
4. 执行日常审计；
5. 生成静态构建；
6. 将未发布稿同步到真实 V3 Reader。

该动作的目标是快速得到“成刊候选预览”，不是直接上线。它不会自动改变发布状态、绕过 TTS/媒体严格审计，也不会调用服务器部署器。

## 工作区空间

桌面默认结构：

`期刊栏 | 页面结构 | 编辑区 50% | 拖拽条 | Reader 50%`

可独立收束前两栏。拖动编辑/Reader 分隔线时只在 30%～70% 之间变化，避免任一侧被拖到不可操作。布局保存在当前浏览器 localStorage。

小于等于 900px 时停止使用桌面拖拽工作区，恢复安全的纵向编辑模式。
