# V3 Beta 发布冻结规则

## 冻结原则

Beta1 之后，默认不再新增大型页面类型、内容块类型或制作中心一级入口。优先级改为：

1. 修复回归；
2. 修复审计漏报/误报；
3. 修复边界；
4. 提升发布恢复能力；
5. 必要的小型可用性修正。

## 历史刊 baseline

`baselines/v3-beta1.json` 是回归保护，不是不可修改的数据源。已发布历史刊若需要修订，应：

```text
Studio 修订 → 自动快照 → 未发布修订 → 审计 → release:check → publish → 人工确认 → 更新 baseline
```

禁止只修改 baseline 来绕过回归。

## 发布失败原则

发布失败不得破坏最后一份完整发布包。Beta1 通过 staging 目录生成并使用同文件系统 rename 完成切换。

## 正式版前仍需人工完成

- 在完整仓库检查 `1/assets`、`2/assets`；
- 在实际部署服务器验证 Nginx 路径和缓存策略；
- Edge / Safari 做人工抽检；
- 第三期真实生产数据完成一次完整“导入 → 编辑 → 媒体 → TTS → 审计 → 发布 → 回滚演练”。
