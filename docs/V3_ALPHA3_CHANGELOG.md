# V3.0-alpha3 变更记录

V3.0-alpha3 的目标不是继续增加栏目，而是冻结一套可以稳定承载后续期刊的阅读内核。本版本以第二期 29 个阅读页为真实回归样本。

## 关键修复

### 1. 恢复真实书本跨页语义

alpha2 在桌面端把“封面 + 卷首语”直接并排展示，与稳定版不一致。alpha3 改为：

- 首跨页：左侧空白页 + 右侧封面；
- 第二跨页：编号 01 + 编号 02；
- 后续按真实纸质书逻辑成对展示；
- `?page=N` 仍然以实际阅读页为定位单位，不会因为双页布局丢失直达能力。

### 2. 恢复 PC 大屏占比

桌面阅读区不再固定为窄书本容器，而是按视口尺寸伸展：

- 1366×768；
- 1920×1080；
- iPad 横向/大尺寸窗口。

字号根据实际书页尺寸动态换算，避免“大屏上书太小”或“文字突然过大”。

### 3. 手机跟手翻页

手机端从简单“滑一下切页”升级为跟手拖拽：

- 手指横向移动时，当前页同步旋转；
- 根据拖动距离与速度判断提交/回弹；
- 纵向滚动优先，不抢正文上下阅读手势；
- 点击页左/右区域仍可翻页。

### 4. 手机动态视口适配

新增 `visualViewport` 几何同步：

- 浏览器地址栏伸缩时重新计算书页；
- 刘海屏/动态工具栏场景不再靠固定 `100vh`；
- 页内正文过长时允许内部纵向滚动；
- 出现溢出时显示“上滑继续阅读”提示。

### 5. 媒体与沉浸阅读

- 恢复背景音乐默认开启策略（受浏览器自动播放限制时，在首次交互后启动）；
- 自然语音 MP3 优先，失败时回退浏览器中文 TTS；
- 连续听刊按照实际物理页 `+1` 前进，修复桌面双页模式下可能跳页的问题；
- 视频保留 `preload="metadata"`；
- 视频使用自定义全屏覆盖层，降低移动浏览器原生全屏兼容问题；
- 手机全屏优先尝试系统 Fullscreen API，失败时进入沉浸模式。

## 回归测试

新增 `scripts/browser-regression-v3.mjs`，通过真实 Chromium + DevTools Protocol 自动验证：

- iPhone 390×844；
- Android 412×915；
- iPad 820×1180；
- Desktop 1366×768；
- Desktop 1920×1080。

测试覆盖首跨页结构、正反向翻页、移动拖拽、目录、文章弹窗、字号、视频全屏以及横向溢出。
