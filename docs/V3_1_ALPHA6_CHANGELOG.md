# V3.1-alpha6 Changelog

## 新增：整刊编排台

- 顶部“内容”菜单新增“整刊编排”。
- 可按稿件维护：标题、栏目、页面类型、计划页数、首选版式、制作状态和备注。
- 实时显示计划稿件数、计划正文页、当前缺失页和栏目数量。
- 制作状态分为：待制作、制作中、已完成、暂缓。

## 新增：当前期刊 / 参考期刊转计划

- “从当前期刊同步”只读取现有正文页并建立制作计划，不新增页面。
- “参考上一期栏目”读取另一 V3 期刊的栏目/类型/页数结构，仅建立待制作计划。
- 连续的 `标题（1）/标题（2）...` 会合并为一个多页计划项。
- 参考期刊动作不会复制正文、媒体或文章绑定。

## 新增：缺失页面骨架批量生成

- 仅为当前计划中尚未匹配的目标页生成页面。
- `hold` / 暂缓计划自动跳过。
- 多页稿件生成 `标题（1）...标题（N）`。
- 使用既有页面模板和 Alpha5 六套版式，不引入新的 Reader schema。
- 计划备注和计划 ID 不会写入期刊页面。
- 操作必须显式确认，不自动保存正式期刊、更不自动发布。

## 新增：本地编排提示

确定性分析：

- 缺失页面；
- 未归类栏目；
- 暂缓稿件；
- 栏目页数过度集中；
- 版式过于单一；
- 200 页容量边界。

提示只用于制作决策，不是正式发布 gate。

## 新增：计划 Sidecar 与服务端边界

- `.v3-editorial-plans/<issueId>.json`。
- 最多 120 个计划项。
- 单稿计划 1–8 页。
- 计划正文页合计最多 180 页。
- 服务端拒绝未知字段、正文、媒体/文章绑定、结构页类型、越界页数和跨期 `issueId`。
