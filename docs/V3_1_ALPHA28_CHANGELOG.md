# V3.1 Alpha28：安全拆页

## 本阶段目标

针对普通用户“拆页容易、搬页需要手工重建”的问题，在制作中心增加可预览、可回退的“选中内容块 → 移动到新页”流程。

## 已完成

- 快速操作栏增加“拆分到新页”，版面健康弹窗同步提供入口。
- 执行前展示来源页保留内容与新续页移动内容，用户可先确认页面差异。
- 仅移动原有顶层内容块，不复制、不重建正文；内容块稳定 ID 保持不变。
- 新续页自动继承来源页的栏目、版式和发布设置，并使用“（续 N）”标题。
- 封面、目录、尾页、全选内容、缺少稳定 ID、页数达到上限时阻止操作。
- 拆页写入独立历史组 `page-split`，支持现有撤销链路；完成后自动同步 JSON、页面导航、Reader 预览和多窗口状态。
- 版面健康提示明确引导用户使用“拆分到新页”，减少发现功能的成本。

## 验证

运行：

```bash
npm run test:v31-alpha28
```

该冒烟测试覆盖 UI 入口、拆页执行契约、稳定 ID、边界保护、历史记录与样式契约。
