# Alpha21 Canvas Workspace 2.0 验收说明

## 桌面工作区

目标结构：页面/编辑区 → Reader 主画布 → Context Inspector。Reader 画布应获得最大的中间区域，Inspector 只显示当前上下文相关属性。

### 缩放

- `适合页面`：完整页面优先装入可用画布。
- `适合宽度`：按可用宽度放大，允许纵向滚动。
- `25%–200%`：手动缩放；Ctrl/Cmd + 滚轮按预设步进调整。

### Inspector

1. 清空组件选择，检查页面健康与 Page ID。
2. 选择正文，检查字号、对齐、宽度、间距与 Block ID。
3. 选择图片/视频，检查媒体操作。
4. 选择容器，检查布局、列距与移动端策略。
5. 多选两个组件，检查批量属性。
6. 重排组件后确认 Inspector 仍指向原 Block ID。

## 手机工作区

手机端不追求桌面自由排版；顺序为 Reader → Inspector → 详细编辑，Inspector 作为紧凑属性层，避免强行压缩四列桌面布局。
