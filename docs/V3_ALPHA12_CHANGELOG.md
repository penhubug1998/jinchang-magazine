# V3.0-alpha12 变更说明

Alpha12 将制作中心的“媒体库”升级为媒体制作工作台，重点解决图片显示、视频封面、媒体引用安全和 TTS 页面对应关系。

## 图片

- 图片块新增非破坏式显示字段：`frameRatio`、`fit`、`positionX`、`positionY`。
- 制作中心新增“图片裁切与焦点”可视化对话框。
- 支持自动 / 16:9 / 4:3 / 3:2 / 1:1 画框。
- 支持 `contain` / `cover`。
- 支持水平、垂直焦点 0–100%。
- 上传 JPG / PNG / WebP 时可在浏览器端自动缩放到最长边约 2000px，并优先转换为 WebP；不会覆盖已有文件。
- Reader 与快速预览均读取同一组图片显示字段。
- 未绑定图片资源时，裁切/焦点编辑器不会打开空预览，而是先提示绑定图片。

## 视频

- 视频块新增 `poster` 字段。
- 可从图片库直接选择视频封面。
- 对 managed assetSource，可调用本机 ffmpeg 自动从视频生成独立 JPEG poster。
- Reader 使用 `<video poster>`，不修改原视频。

## 媒体引用安全

- 资源列表展示体积、图片/视频尺寸、视频时长、引用状态与引用数量。
- 可查看媒体被哪一页、哪个内容块、哪个字段引用。
- 正在被引用的资源禁止删除，API 返回 `ASSET_IN_USE` 和引用位置。
- 未引用资源支持“预检 → 确认删除”的清理流程。
- 历史 / 外部资源目录继续保持只读。

## TTS 页面对应关系

- `features.narration` 新增：
  - `sourceDigest`
  - `pageDigests`
  - `baselinedAt`
- 指纹只围绕实际朗读文本生成，不因图片焦点等纯视觉设置变化而误报。
- 页面标题、正文、说明文字或顺序变化后，审计会产生 `TTS_SOURCE_STALE`。
- 严格发布阶段，TTS 已过期属于阻断项。
- 重新生成全部逐页音频后，可执行：

```bash
npm run tts:baseline -- --issue 003
```

也可以在媒体工作台点击“确认朗读已重新生成”。

## 边界

- 图片焦点只能为 0–100。
- 画框比例仅接受 `auto / 16:9 / 4:3 / 3:2 / 1:1`。
- fit 仅接受 `contain / cover`。
- poster 继续受媒体路径长度与项目目录边界限制。
- 删除、清理、自动 poster 只允许写入 `issues/<id>/assets` 管理目录。
- 320px 极窄屏下媒体摘要固定为 2×2，避免纵向信息堆叠挤压资源列表。
