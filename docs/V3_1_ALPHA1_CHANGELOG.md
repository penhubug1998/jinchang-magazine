# V3.1-alpha1 变更说明

## 目标
从固定内容块编辑器迈向“受约束的自由创作”，先建立 Container + Layout 基础，不引入无限自由画布。

## 新增
- `container` 内容块，支持 7 种布局：单栏、双栏 5:5、4:6、6:4、三栏、图左文右、文左图右。
- 容器列间距 `sm/md/lg`、垂直对齐 `start/center/stretch`、移动端 `stack/preserve`。
- Studio 新增“＋布局”直达入口和可视化列编辑器。
- 容器列内可添加正文、引言、编号卡片、案例、图片、视频、祝福语，并支持排序/删除/媒体选择。
- Reader 递归渲染容器；手机默认自动堆叠为单列。
- 页面模板库新增双栏专题、图文专题、三栏速览。
- 媒体引用与 TTS 正文指纹递归进入容器。
- 审计可定位容器内媒体；移动端保留多栏时给出可读性警告。

## 边界
- 容器 1–3 列。
- 单列最多 20 个子块。
- V3.1-alpha1 暂不允许容器嵌套容器。
- 单页顶层块最多 80，总递归块最多 160。
- 手机默认 `stack`；`preserve` 属高级选项。

## 兼容性
- V3.0 既有 9 类页面与 14 类内容块保持读取兼容。
- 当前开发版本为 `3.1.0-alpha.1`；V3.0 正式发布锁仍固定 `v3StableVersion=3.0.0`。
