# V3.1-alpha2 Changelog

## 新增

- 可视化样式设计器。
- `issue.design.tokens` 全刊 Theme。
- `page.design` 页面覆盖。
- `block.design` 组件覆盖，容器内子块同样支持。
- Reader 三级样式继承与动态 CSS token。
- 样式参数服务端边界与设计可读性审计。
- V3.1 Alpha2 样式矩阵和五档浏览器回归。

## 边界

- 颜色仅接受 `#RRGGBB`。
- 组件字号 10–48px、宽度 25–100%、边框 0–6px 等均有硬上限。
- V3.0.0 正式发布锁保持独立。
