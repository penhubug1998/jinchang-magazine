# V3.0-alpha7 Changelog

## 目标

把制作中心从 JSON 辅助编辑器升级为可视化内容块编辑器，同时继续保持 alpha6 已建立的界面边界与发布审计闭环。

## 可视化内容块

制作中心默认进入“可视化”模式，支持：

- 正文段落 paragraph
- 引言/提示 quote
- 标签组 chips
- 编号卡片 cardline
- 案例 + 警示 casePair
- 目录 toc
- 图片 image
- 视频 video
- 文章链接 articleLink
- 封面副信息 coverMeta
- 封面栏目 coverSections
- 祝福语 blessing
- 制作单位 producer
- 通用卡片组 cards

每个内容块支持上移、下移、复制、删除；桌面指针设备额外支持拖拽排序。移动端不依赖拖拽，避免触控冲突。

## 双模式

- 默认：可视化内容块
- 高级：原始 blocks JSON
- 两种模式直接维护同一份 `page.blocks` 数据
- JSON 语法错误时禁止切回可视化/保存
- 可视化修改后实时同步 JSON

## 实时预览

当前页提供 Studio 内实时缩略预览，用于快速发现：

- 内容层级异常
- 页面信息密度过高
- 封面/尾页主题不协调
- 图片/视频位置问题
- 潜在页面溢出

最终发布仍以 build + 五档真实浏览器回归为准。

## 审计可用性

alpha6 的“定位”继续保留，并扩展到 blockIndex：

- 元数据问题 -> 对应字段
- 页面标题/类型 -> 对应页面字段
- 内容问题 -> 第 N 页第 M 个内容块
- 媒体问题 -> 对应页面中引用该资源的内容块

## 新边界

- 单页最多 80 个内容块
- 单个数组型块最多 40 个条目
- 单个深层文本字段最多 12000 字符
- 媒体路径最多 500 字符
- 服务端再次校验，不依赖浏览器前端限制

## 回归

`npm run verify:v3` 包含：

- 数据校验
- 构建
- 阅读器 smoke
- 生产链 smoke
- 制作中心 API smoke
- 可视化编辑器 smoke
- 期刊五档 Chromium
- 制作中心五档 Chromium

制作中心浏览器回归会真实执行：添加块、复制块、可视化/JSON 双向切换、审计页面定位、审计元数据定位、审计内容块定位。
