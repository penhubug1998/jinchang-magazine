# V3.0-alpha8 Changelog

## 目标

Alpha8 聚焦“制作效率 + 边界稳定性”，把 Alpha7 的可视化内容块编辑继续推进为更完整的期刊制作工作台。

## 新功能

### 1. 页面模板库
- 新增通用文章、时政资讯、理论学习、反诈/安全、警示教育、养生知识、图文、视频、尾刊寄语 9 类模板。
- 支持“插入模板页面”和“套用到当前页”。
- 封面、尾页作为结构边界页，不允许直接被普通模板替换。
- 已存在尾页时不允许再添加第二个尾页。

### 2. 自动目录
- 新增 `栏目归属` 字段。
- 目录优先使用 `section`，缺失时再从导航标题/眉题推断。
- 自动生成目录前先计算条目数和最终页码。
- 超过单块 40 个目录项时直接中止，不写入非法半成品数据。

### 3. 新建一期复制结构
- 新建期刊时可选择一个既有 V3 期刊作为结构来源。
- 复制页面类型、栏目结构和内容块形状。
- 不复制旧文章正文、不复制旧媒体文件、不继承旧媒体路径绑定。
- 新一期始终使用自己的 `issues/<id>/assets`。
- 结构来源在创建新期刊前先校验，避免失败后残留空期号目录。

### 4. 媒体资源库
- 图片/视频内容块可以直接选择媒体，不必手写路径。
- 新刊自己的 `issues/<id>/assets` 支持上传。
- 历史/外部 `assetSource` 为只读，防止通过制作中心覆盖线上稳定资源。
- 上传具备：类型白名单、单文件体积限制、文件头签名校验、中文文件名、路径边界、同名自动重命名。
- 当前限制：图片 8MB、视频 80MB、音乐 20MB、朗读音频 8MB。

### 5. 外部文章库
- 可视化维护 `issue.articles`。
- 支持文章标题、副标题/日期、HTTPS 原文链接、摘要段落、来源说明。
- 删除被 `articleLink` 引用的文章时，会同步清空引用并交由审计提示重新绑定。
- 服务端限制最多 100 篇、每篇最多 50 段，并对 URL/字段长度做硬校验。

### 6. 编辑—成刊联动预览
- 快速预览：继续实时反映编辑内容。
- 成刊预览：调用真实 V3 构建器并嵌入阅读器。
- 编辑发生变化后明确显示“成刊预览待刷新”，避免误把旧构建当作当前版本。

### 7. 页面筛选与定位边界
- 最高 200 页的期刊可按标题、栏目、类型筛选。
- 审计定位到被筛选隐藏的页面时，自动清空筛选并显示目标页。

## 边界修复
- 自动目录不再生成超过 40 项的非法 block。
- 克隆无效结构来源不会留下半创建期刊。
- 历史资源目录禁止写入。
- 同名上传禁止静默覆盖。
- 媒体扩展名与真实文件头不匹配时拒绝上传。
- `page.section` 新增服务端 120 字符边界。
- `articles` 新增数量、字段、URL、段落数量与单段长度边界。
- 模板、媒体、文章三个大弹窗在 320px 宽度下均可滚动且不横向越界。
