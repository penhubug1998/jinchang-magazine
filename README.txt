中国人民银行金昌市分行离退休干部电子期刊｜3D仿真翻页H5终版

目录结构
- index.html
- assets/video/discipline.mp4        已嵌入用户提供的纪律提醒视频
- assets/music/README.txt            背景音乐配置说明

主要功能
1. PC端双页3D仿真翻页。
2. 手机端支持手指左右拖动翻页，使用 translate3d + requestAnimationFrame 优化，降低卡顿。
3. 所有期刊网页链接改为“查看链接内容”，点击先在H5内弹出内容摘要，再可选择打开原网页。
4. 已根据“老干部期刊第一期 终.docx”更新终版内容，新增“习近平党建思想 / 《习近平党建文选》第一卷、第二卷”学习页。
5. “离退休干部电子期刊”统一改为“中国人民银行金昌市分行离退休干部电子期刊”。
6. 已将上传的 MP4 视频插入“第五版块 离退休纪律提醒”页。
7. 已生成背景音乐模块：
   - 点击顶部“♫ 音乐”打开音乐面板；
   - 可临时选择本地音频播放；
   - 正式部署时，把背景音乐命名为 bgm.mp3 放入 assets/music/ 即可。
8. 支持目录跳转、页码进度、全屏阅读、键盘方向键翻页。

部署
- 本地预览：建议使用一个静态HTTP服务器打开，不要直接双击 file://，这样视频与音乐资源兼容性更好。
- Nginx / 静态空间：将整个文件夹原样上传，首页指向 index.html。


v2新增功能
---------
1. 每个内置插画区域都增加“替换图片/调整图片”按钮：
   - 可直接上传 JPG、PNG、WebP 等图片；
   - 可选择“填充区域”或“完整显示”；
   - 可调整缩放、水平位置、垂直位置；
   - 可恢复默认插画；
   - 自定义设置会尝试保存在当前浏览器本地。
   注意：浏览器内上传只改变当前浏览器中的显示效果，不会自动把图片写回ZIP文件。

2. PC端阅读区改为接近全屏：
   - 主体自动填充浏览器可用区域；
   - 仅保留左右两侧翻页按钮和顶部/底部控制区域；
   - 大屏字体与内容区域同步放大。

3. 修复PC端向左翻页：
   - 改为当前左页从左向右反向翻转；
   - 修正前后页内容映射；
   - 修正反向阴影方向；
   - 与向右翻页使用相同的GPU transform动画路径，减少卡顿。

4. 手机端继续使用轻量 translate3d 拖动翻页，避免加载PC端较重的3D反向动画。
