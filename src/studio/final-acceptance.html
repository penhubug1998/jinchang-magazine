真实设备怎么验收

先在命令行开始 P1-11 Session，再在对应设备打开验收链接。设备记录会绑定当前 Git commit、Session 所属源码、记录时间与 SHA-256；源码变化后旧记录自动失效。

P1-11 操作顺序

1. 开始会话：npm run final:v31:session:start -- --issue <期号>
2. 当前 E2E：npm run test:p1-08
3. 完整媒体：npm run test:v31-rc2-media-local
4. Edge / Mac Safari / iPhone Safari / Android 微信：在上方真实设备逐项提交
5. 正式环境：npm run final:v31:production-receipt -- --issue <期号>
6. 状态汇总：npm run final:v31:session:status
7. 导出证据包：npm run final:v31:evidence:bundle
8. 离线校验：npm run final:v31:evidence:verify
9. 8/8 后封存：npm run final:v31:session:seal
10. 最终封包门禁：npm run final:v31:package-guard

Session 开始后不要再提交源码改动。任何新 commit 都会使这次会话变为 STALE，必须重新开始。
